§01 Brand essence

We sound like an engineer wrote it.
Because one did.

OpenIT is honest, direct, and a little dry. We don't talk about "AI transformation" — we talk about tickets, queues, scripts, and saving you time. The product is open source, so the brand should feel like a craftsperson's tool, not enterprise software.

Personality

Editorial, not corporate

Long, confident sentences. Real punctuation. We use em-dashes, not exclamation marks.

Tone

Warm, with a hard edge

Cream paper feel, terracotta accents. Black ink underneath. Soft on the eye, certain in opinion.

Voice samples

"Claude Code is the operating system."

"Answer once. Claude handles the next one." · "If you can run it in a terminal, Claude can use it."

Pairing rules

Light surface

Ink type on Cream / Cream Deep.
Terracotta only for the accent word + the dot in pills.

Dark surface

Cream type on Ink.
Terracotta Soft for the accent (not the base terracotta).

Never

No green, no blue, no purple, no gradient ramps. One accent. One.

Three faces. Used carefully.

§06 Iconography

Lucide-style. 2px stroke.

We use Lucide as the system icon set — 24×24 canvas, 2px stroke, round caps and joins. No filled icons. No two-tone. Inline SVG, never icon fonts.

§07 Layout & spacing

Generous. On purpose.

Marketing surfaces breathe — 80–120px vertical padding between sections, max content width ~1240px. Product surfaces tighten — 16–24px. Alternate cream and cream-deep sections to create rhythm. Never two cream-deep sections in a row.

Base unit
4px

All spacing snaps to a 4px grid. Common stops: 8, 12, 16, 24, 32, 48, 64.

Radii

6 · 12 · 18 · 999. Pills and surfaces — nothing in between.

Shadows

Hairline, soft, atmospheric. We don't use mid-level Material shadows.

§08 Do & Don't

The non-negotiables.

Do

  • Set headlines tight — letterspacing -0.025em, line-height 0.92.
  • Use Fraunces italic for one phrase per paragraph, ideally the punchline.
  • Pair "Open" Inter 800 with "IT" Fraunces italic 500 terracotta. Always.
  • Keep terracotta to ~5–8% of the page surface. It's an accent, not a fill.
  • Use full-radius pills (999px) for everything inline-status-like.
  • Alternate cream and cream-deep sections to break up long pages.
  • Use em-dashes — they're load-bearing in our voice.
  • Inline SVG, 2px stroke, round caps. Lucide is the system.

Don't

  • Don't stretch the wordmark, recolor it, or set it in all-caps.
  • Don't add a second accent color. No blue, no green, no purple.
  • Don't use Fraunces for body or buttons — it's a one-phrase tool.
  • Don't use exclamation marks or emoji in product or marketing copy.
  • Don't use filled or two-tone icons, and never icon fonts.
  • Don't use gradients. The brand is paper + ink, not glass.
  • Don't say "AI" when you can say "Claude". Don't say "transformation" ever.
  • Don't put two cream-deep sections in a row.
