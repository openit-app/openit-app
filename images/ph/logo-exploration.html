OpenIT · Logo exploration · v1

Six directions for the OpenIT mark.

Each option is shown at three sizes (display, app-shell, favicon-ish) on both light and dark surfaces. Below each, a short note on what it's saying and a pro/con. Pick the one that fits — or mix two.

01 · The current wordmark Inter 800 + Fraunces italic
OpenIT OpenIT OpenIT
Editorial Echoes the headline pattern A bit generic — many products do this

The pattern you have now. Neutral "Open" + accented italic "IT". Clean and editorial but doesn't lean into the technical / Claude-Code / pixel-mascot identity we've built around it.

02 · Pixel "OPEN" + italic "IT" Press Start 2P + Fraunces italic
OPENIT OPENIT OPENIT
Bridges retro CLI + editorial warm Rhymes with "CLAUDE CODE" lockup Harder to read at small sizes

Same idea as your CLAUDE-style lockup, applied to the brand itself. "OPEN" stays small + pixel, "IT" is the loud italic finale.

03 · Mono lowercase CLI tool JetBrains Mono 600
openit_ openit_ openit_
Feels like a CLI tool you trust — like git, ssh, kubectl Reads as developer-first Loses the editorial italic warmth

Lowercase, mono, with a terracotta cursor at the end. Says "I'm a humble Unix tool, not a SaaS product." Closest in spirit to Ghostty / fly / brew.

04 · Mascot + wordmark Pixel mark + Inter / Fraunces
OpenIT OpenIT OpenIT
Has a real iconic mark Mascot doubles as favicon / app-icon Reuses the Claude Code mascot — needs differentiation

The mark + wordmark approach (like Anthropic, Vercel, Linear). The mascot becomes the iconic shape; the wordmark is supporting. Caveat: we'd need to make this mascot visually distinct from Claude's — different color, different shape, etc.

05 · All Fraunces italic Fraunces italic 500
OpenIT OpenIT OpenIT
Magazine / editorial confidence Reads as a single word, not a hybrid Loses the contrast that makes "IT" pop

Fully editorial. Like a literary masthead. The whole thing is in Fraunces italic — "Open" in ink, "IT" in terracotta. Looks like the cover of a thoughtful magazine. Probably too soft for a tech product, but striking.

06 · Bracketed code-style JetBrains Mono 600
<openit/>
<openit/>
<openit/>
Unmistakably technical / open Reads as XML-ish / JSX-ish May feel too "web framework" not "IT tool"

Self-closing tag style. The brackets are dim, "open" is neutral, "it" is terracotta. Says "I'm just code." Possibly too dev-framework-coded for an IT helpdesk audience, but very distinctive.

Recommendation

Keep option 01 as the primary wordmark — but adopt option 04's mark as the icon.

Two-piece system: the existing OpenIT wordmark stays as your primary brand-name treatment everywhere typography appears, but we design a distinct pixel mark (not the Claude mascot — something OpenIT-specific) to be the favicon / app icon / social avatar. That gives us a recognizable shape without trampling on Claude's identity, and preserves the editorial wordmark you've built equity in.

If you want to go bolder for the launch and lean fully into the CLI / pixel ethos, option 03 (mono openit_) is the strongest second pick — it lands like a serious dev tool, not a SaaS product.
